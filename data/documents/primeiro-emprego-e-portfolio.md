# Primeiro emprego em tecnologia: portfólio, currículo e entrevistas

Fonte: experiência do ministrante, Igor Sasaki (Tech Lead e Engenheiro Full Stack Sênior, ex-aluno do
Técnico em Informática do IFSP Araraquara). Este documento é opinião profissional, não regra oficial.

## O que um recrutador de vaga júnior ou estágio procura
- Base sólida: lógica, uma linguagem bem aprendida, Git, SQL básico e HTTP/APIs.
- Evidência de que você constrói coisas: projetos no GitHub com README caprichado.
- Capacidade de aprender e de se comunicar: explicar o que fez, o que deu errado e como resolveu.
- Ninguém espera que um júnior saiba tudo. Esperam que ele saiba pedir ajuda e evoluir rápido.

## Portfólio que funciona
- Dois ou três projetos bem feitos valem mais que vinte tutoriais copiados.
- Cada projeto precisa de README com: o problema, como rodar, prints, tecnologias e o que você aprendeu.
- Coloque no ar (deploy) quando possível: link clicável impressiona mais que código.
- Ideias de projeto: uma API como a deste minicurso, um app para um negócio da família, um sistema
  para a sua escola, um bot útil para o seu grupo de estudos.
- Projetos com IA generativa bem integrada (JSON estruturado, RAG) são um diferencial hoje.

## Currículo de quem nunca trabalhou
- Uma página. Comece por um resumo de 2 linhas com o que você sabe fazer.
- Liste projetos como se fossem experiências: o que fez, com qual tecnologia, qual resultado.
- Inclua o curso técnico, olimpíadas, hackathons, monitorias, trabalho voluntário e cursos relevantes.
- Link para GitHub e LinkedIn atualizados.

## Entrevista técnica para júnior
- Espere perguntas sobre seus próprios projetos: conheça cada linha do que você publicou.
- Pode haver teste prático (desafio técnico para fazer em casa) ou live coding simples.
- Pense em voz alta. Mostrar o raciocínio conta tanto quanto acertar.
- Perguntas comportamentais são comuns: conte uma situação real usando contexto, ação e resultado.

## Usando IA para estudar sem se sabotar
- Use a IA para explicar conceitos, revisar seu código e gerar exercícios.
- Não entregue código que você não entende: na entrevista você vai precisar explicar.
- Escreva primeiro, peça revisão depois. É assim que se aprende.

## Faculdade ou mercado?
Não precisa ser um ou outro. Muitos estudantes trabalham ou estagiam enquanto fazem a graduação.
A graduação abre portas para concursos, pós-graduação e algumas empresas que exigem diploma;
o mercado valoriza muito a experiência prática e o portfólio. O melhor caminho é o que você consegue
manter com constância.
